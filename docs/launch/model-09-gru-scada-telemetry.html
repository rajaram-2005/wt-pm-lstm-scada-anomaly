GRU SCADA Telemetry

A one-step-ahead GRU forecaster over the 12 SCADA channels whose prediction error is the anomaly score. It is the cheapest sequence detector in the collection and the one that runs on an edge CPU, which makes it the default continuous monitor.

Advanced concepts

The ideas this model actually leans on, each stated with its failure mode.

Update and reset gates

The GRU's reset gate decides how much past state to forget and the update gate how much new candidate state to admit. Two gates instead of the LSTM's three is why this model fits an edge CPU's latency budget at 2 s per window.

One-step versus multi-step

A one-step forecast error is a residual, not a horizon forecast: it says 'this moment did not follow from the last few', which is the right question for detection and the wrong one for planning. Horizon forecasting is m06's job.

Standardising the residual

Raw squared error scales with the channel's own range, so a gusty day looks like a fault. The adapter standardises error before it becomes a score - the reason the fusion layer can compare this vote with SVDD and VAE distances at all.
