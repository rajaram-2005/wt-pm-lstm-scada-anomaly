Informer Long Sequence

A long-horizon transformer forecaster for farm power, built on sparse attention that scales linearly instead of quadratically in sequence length. Its forecast residual is an anomaly signal, and its horizon is what makes day-ahead planning possible at all.

Advanced concepts

The ideas this model actually leans on, each stated with its failure mode.

Sparse attention

Only the queries with the most 'active' attention distributions are evaluated, reducing cost from O(L^2) to O(L log L). That is the entire reason a long-horizon transformer is deployable on 10-minute SCADA at all.

Distilling layers

Each encoder layer halves the sequence, so depth buys global context instead of memory. The trade is resolution: fine structure must be captured early or it is gone.

Partial - and labelled that way

Upstream ships a placeholder attention implementation. The adapter runs the real graph but the attention is not the published ProbSparse kernel, so the forecast error is honest but the architecture claim is not. Marking it partial is the point.
