SNN Event Vibration

A spiking neural network that consumes vibration as asynchronous threshold-crossing events rather than as a sampled waveform, and reads out class evidence from spike rates. It is the collection's ultra-low-power path: spikes cost energy only when they fire.

Advanced concepts

The ideas this model actually leans on, each stated with its failure mode.

Spikes as a data format

Delta encoding throws away everything that did not change. On a wind turbine that is most samples, which is the real energy argument - not the network, the fact that steady state costs nothing to transmit.

Surrogate gradients

A spike is a step function with zero derivative almost everywhere, so backpropagation needs a surrogate gradient. That approximation, not the spiking itself, is where the accuracy comes from - and where it is most fragile.

Membrane potential as evidence

Reading the differentiable membrane potential rather than raw spike counts gives a smooth, fusable score. The adapter uses it exactly like any other softmax voter, so the fusion engine needs no special case for neuromorphic hardware.
