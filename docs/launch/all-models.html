Platform layers

Every model page names the layers it participates in. The layers themselves are defined once, in the catalog.

Fusion engineCombines the votes of the 25 models into one answer.
Weighted, confidence-weighted, max and median rules; inverse-variance weighting when a model reports uncertainty; coverage-aware probability fusion so a voter that abstains on a class does not dilute it.
models: 03, 04, 06, 09, 10, 11, 12, 13, 16, 18, 20, 21, 22, 23, 25
Calibrated uncertaintyEvery alert carries an interval or a confidence, not just a number.
MC-sampled Bayesian weights (m18), latent-posterior spread (m22), a particle posterior (m16) and the LSTM detector's own interval; expected calibration error is computed at evaluation time.
models: 13, 16, 15, 22
Drift and data trustDetects that the world, or the sensor, has moved.
Rolling distribution comparison between training and live features (evaluation.drift_report) plus an unsupervised SensorQualityMonitor for freeze, spike, stuck-at and out-of-range conditions.
models: 02, 03, 05, 06, 13
ExplainabilityTurns an alert into a root cause an engineer can argue with.
m21 SHAP TreeExplainer attributions, contrastive healthy-band z-scores, per-feature counterfactuals, and a Hermes narrative rendered only from real outputs.
models: 24, 25, 18, 01
Physics constraintsKeeps the learning inside what the machine can actually do.
A digital-twin surrogate (m19) supplies residuals and what-if counterfactuals; the PG-BNN (m18) embeds P = tau * omega as a soft penalty and returns physics-consistent uncertainty.
models: 07, 16
Safety gateThe one path that is allowed to say STOP.
A depth-5 decision tree exported to model.h for an ESP32 (m25) plus a mirrored in-process SafetyManager evaluating the same hard limits, with hysteresis and cooldown in the alert manager.
models: 22
Evaluation protocolMakes every number in the collection comparable.
Leak-free window masks, past-only holdout state, ROC-AUC / PR-AUC / calibration / RUL metrics, an experiment tracker, and the fidelity ladder that labels every claim rung 1.
models: 13, 01, 03, 05, 15
Hermes agentA Thought -> Action -> Observation loop that decides which model to ask next.
Eight tools: sensor_quality, anomaly, diagnose, explain, rul, safety, what_if, finish. Observations are adapter outputs; the agent never invents a measurement.
models: 13, 24, 22, 07, 16, 15, 09, 25
