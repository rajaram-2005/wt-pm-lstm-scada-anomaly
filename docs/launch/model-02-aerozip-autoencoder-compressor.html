AeroZip Autoencoder Compressor

An 8:1 bottleneck autoencoder that squeezes a 64-column telemetry table into an 8-dimensional latent vector for low-bandwidth cellular or satellite backhaul. The same latent doubles as a feature stream for the rest of the collection, so compression is not a separate pipeline stage - it is the first one.

Advanced concepts

The ideas this model actually leans on, each stated with its failure mode.

Rate-distortion, not just dimension

8:1 is a count of dimensions, not of bytes actually sent. A defensible bandwidth claim needs entropy-coded latent bitrates measured on real backhaul traces - the model reports compression_ratio() and nothing more.

Reconstruction error as a free detector

An autoencoder trained on healthy telemetry misfits when the plant changes. The same forward pass therefore yields two products: a latent for backhaul and a scalar residual that behaves like an unsupervised anomaly score.

Latent as transferable features

The bottleneck is reused as the input view for the tabular voters (m10, m11) and the SSL encoder, so a cheap linear layer at the edge can produce features the cloud classifiers already understand.

Honest limits

  • Backhaul byte savings are not measured - only the dimensional ratio is
  • Latent quality is validated on simulator statistics, not on a real link budget
